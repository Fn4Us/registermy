How to Register a DMHS.club Link

YourClubName.dmhs.club

Google Classroom join link, Google Forms link, etc.

Any DMHS.club link that connects to either Google Classroom, Google Forms, or anything else that does not support custom URLs will use URL Forwarding. When putting in your website's link, it will bring you to the Classroom join link or other link you provide. An example can be found at https://urlforwarding.dmhs.club, which brings you to the DMHS website.

All information needed to be provided is the link you wish to redirect to.

If it is for Google Classroom, ensure it looks like the following: classroom.google.com/c/ODcyMDY5MzY5NjEz?cjc=yfa2ht2y

If it is for Google Forms, ensure the permissions are set properly, and ensure the link looks like the following: forms.gle/ShBQdZHiCmkrJndK6

Google Sites

Google Sites will require a 3-way back and forth. Watch the video for how to get your TXT record, and send that to me. NOTE: In the video, where he inputs "www", you will need to input whatever you wish the text before "dmhs.club" to be in your URL. Then, the rest of the input will be "dmhs.club". Once I set the TXT record, I'll notify you. You will then be able to continue the verification process.

Once you have verified the domain, it will prompt you to enter the CNAME record to "ghs.googlehosted.com". Email me, I will make this change. Once I get back to you, you can press "Done". In approximately 30 minutes or so, the new URL should connect to your Google Sites.

If any problems arise, let me know. An example can be found at https://sitesexample.dmhs.club, which is a prototype site for the Cruciverbalist's Club.

GitHub Pages

If you're using GitHub, I presume you know how to use GitHub pages. Ensure the repo is already live when you request a subdomain. Provide to me the link to the live site and I can set up the CNAME records GitHub requests.

If you would prefer me to use A records, such that I will not have to know your GitHub account, that is fine. GitHub sometimes gets confused when subdomains have A records.

IMPORTANT: If you are using other hosting providers such as Cloudflare, Vercel, Netlify, and others, subdomains like those of DMHS.club will not work. If you can find an alternative hosting service that does allow registration of subdomains, tell me what records I need to add and I will do so.
